# 로또 추첨기 3D 시뮬레이션 + 검출력 시나리오 분석

## 1. 시뮬레이터 구성

- 원통 챔버(반경 0.28m, 높이 0.62m), 구체 45개(반경 22.5mm, 3.2g)
- 중력 + 임펄스 기반 구-구/구-벽 충돌(반발계수 0.62/0.55) + 송풍 난류
- 송풍은 **힘**으로 작용하므로 가속도 a=F/m → 무거운 볼일수록 덜 떠오름
- 사전 혼합 5초 후 상단 배출구 개방, 먼저 통과한 6개가 당첨
- 충돌은 Jacobi 방식(순서 무관), 번호↔자리 배정 무작위화

## 2. 중립성 검증 (질량 동일)

```
9,414회차: 균등성 χ²=49.23 (df 44), p=0.2717 / 번호값 추세 r=0.101, p=0.507
```

## 3. 질량 → 확률 전달함수

```
■ 질량 → 선택확률 전달함수 보정  (레벨당 12,000회차 시뮬)

  질량구배 ±10%  9,610회차 (미완료 2390)  132초
     균등성 χ² = 513.0 (df 44), p = 3.3e-81
     민감도 S = d(ln p)/d(ln m) = -0.753 ± 0.060   (S<0 = 무거울수록 덜 뽑힘)
     1번 대비 45번 빈도비 0.714
  질량구배 ±20%  10,217회차 (미완료 1783)  130초
     균등성 χ² = 1985.2 (df 44), p = 0.0e+0
     민감도 S = d(ln p)/d(ln m) = -0.708 ± 0.028   (S<0 = 무거울수록 덜 뽑힘)
     1번 대비 45번 빈도비 0.574

■ 요약
   선형성 확인: ±10%→S=-0.753  ±20%→S=-0.708
   평균 민감도 S ≈ -0.731
   → 볼 질량이 1% 무거우면 선택확률이 약 0.73% 낮아진다.
   → 선택확률 5% 편향을 만들려면 질량 차이 약 6.8% 필요.
```

## 5. 현실 잉크 질량차 환산

```

   잉크질량차   질량차(%)   확률편향(%)   80%검출 필요회차(추세검정)

   ※ 로또볼 인쇄 잉크는 통상 수 mg 수준. 220mg(=6.8% 질량차)이 있어야

      그 정도면 추첨 전 무게검사에서 즉시 걸린다.

■ 실제 데이터(1,241회차)의 검출 한계
   편향  5%: 추세검정 검출력 24% → 있어도 놓쳤을 가능성이 더 크다

   편향 15%: 검출력 97% → 이 정도였다면 거의 확실히 잡혔다
   → 실측 결과(추세 r=0.057, p=0.755)는 15% 이상 편향을 강하게 배제하지만,
      5% 이하 편향에 대해서는 판정 불가.
```
